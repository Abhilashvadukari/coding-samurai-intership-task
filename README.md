# Rule-Based Chatbot

## Description
The Rule-Based Chatbot is a simple Artificial Intelligence project developed using Python. This chatbot interacts with users through predefined rules and conditional statements. It can respond to basic user inputs such as greetings, questions about its name, and simple conversations. The project demonstrates fundamental AI concepts like pattern matching, string manipulation, and decision-making logic without using machine learning. It is designed to help beginners understand the basics of chatbot development and human-computer interaction.
## Features
- Greets users
- Answers basic questions
- Handles exit commands

## Run the Project
```bash
python chatbot.py
```

## Skills Used
- Python
- Conditional Statements
- String Manipulation
